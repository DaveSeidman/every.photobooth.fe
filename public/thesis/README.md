# Thesis design assets

Source: https://internal-every.hi-23d.workers.dev/photobooth/

Fonts, outlined wordmark and squiggles, illustration, perforated frames and buttons reproduce the provided prototype. `img/profile.svg` is the prototype's simulated camera, used only by the isolated design preview.

The transparent stone animation comes from `/a/every-hero-stone-1/stone.webm` and `/a/every-hero-stone-1/stone.mov` on that host. Chrome and other browsers use VP9 WebM; Safari uses HEVC MOV to retain transparency, matching the prototype's browser selection.

These are supplied brand assets for this project, not a general-purpose asset library.
